# Исправление проблемы с временными метками

## Проблема

При работе с API Bybit возникала ошибка:
```
_http_manager - ERROR - invalid request, please check your server timestamp or recv_window param. 
req_timestamp[1757186439240],server_timestamp[1757190787380],recv_window[7500] (ErrCode: 10002)
```

Эта ошибка возникает из-за рассинхронизации времени между локальным компьютером и сервером Bybit.

## Решение

Добавлена автоматическая синхронизация времени с сервером Bybit в класс `BybitAPI`:

### Новые методы:

1. **`get_server_time()`** - получает время сервера Bybit
2. **`sync_server_time()`** - синхронизирует локальное время с сервером
3. **`get_synchronized_timestamp()`** - возвращает синхронизированную временную метку
4. **`_setup_custom_timestamp()`** - настраивает кастомную генерацию временных меток
5. **`resync_time()`** - выполняет повторную синхронизацию

### Автоматическая синхронизация

При создании объекта `BybitAPI` автоматически выполняется:
1. Получение времени сервера Bybit
2. Вычисление смещения между локальным и серверным временем
3. Настройка кастомной генерации временных меток для всех API запросов

## Использование

### Базовое использование

```python
from bybit_api import BybitAPI
from config import TEST_API_KEY, TEST_API_SECRET

# Создание API объекта с автоматической синхронизацией времени
api = BybitAPI(TEST_API_KEY, TEST_API_SECRET, trade_mode='test')

# Все API запросы теперь используют синхронизированное время
klines = api.get_klines("BTCUSDT", "1", limit=100)
```

### Ручная синхронизация

```python
# Повторная синхронизация времени
api.resync_time()

# Получение информации о синхронизации
print(f"Смещение времени: {api.time_offset} мс")
sync_timestamp = api.get_synchronized_timestamp()
```

## Технические детали

### Как это работает

1. **Получение времени сервера**: Запрос к `/v5/market/time` для получения точного времени сервера
2. **Вычисление смещения**: Разность между серверным и локальным временем
3. **Кастомная генерация временных меток**: Переопределение метода `_generate_timestamp` в HTTP менеджере pybit
4. **Автоматическое применение**: Все API запросы используют синхронизированное время

### Поддерживаемые режимы

- **Testnet**: `https://api-testnet.bybit.com/v5/market/time`
- **Real**: `https://api.bybit.com/v5/market/time`

### Обработка ошибок

- При ошибке получения времени сервера используется локальное время
- Логирование всех операций синхронизации
- Graceful fallback при недоступности сервера

## Файлы изменены

- `templates/test_timestamp.html` - веб-интерфейс для тестирования

## Совместимость

- Работает с существующим кодом без изменений
- Автоматически применяется при создании объекта `BybitAPI`
- Не влияет на функциональность при недоступности сервера времени

## Безопасность

- Синхронизация времени не влияет на безопасность API ключей
- Использует только публичные эндпоинты для получения времени
- Не передает никаких чувствительных данных
