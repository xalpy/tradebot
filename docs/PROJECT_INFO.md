# 📊 Trading Bot Dashboard - Информация о проекте

## 🎯 Цель проекта

Создание современного веб-интерфейса для торгового бота с поддержкой Bybit API, включающего продвинутый бэктестинг, интерактивные графики и автоматическую торговлю.

## ✨ Ключевые особенности

### 🔄 Реальное время
- WebSocket соединение для обновления цен
- Уведомления о сделках в реальном времени
- Мониторинг позиций и балансов

### 📈 Продвинутый бэктестинг
- **3 торговые стратегии**: GhostTangent, OTT, Комбинированная
- Настройка плеча (1x-100x)
- Стоп-лосс (0.1%-50%)
- Размер позиции (1%-100%)
- Анализ причин выхода из позиций
- Уровень уверенности в сигналах (0-100%)
- Детальная статистика сделок

### 🎨 Современный интерфейс
- Темный градиентный дизайн
- Анимации и эффекты
- Адаптивная верстка
- Интерактивные графики LightweightCharts

### 🤖 Автоматическая торговля
- Логика "двойных сигналов"
- Автоматическое управление позициями
- Настройка параметров риска
- Мониторинг производительности

## 📊 Торговые стратегии

### 1. GhostTangent Strategy
**Принцип работы:**
1. **Определение пивотных точек**: Поиск локальных максимумов и минимумов
2. **Генерация сигналов**: Buy на Pivot Low, Sell на Pivot High
3. **Управление позициями**: Логика разворота при противоположных сигналах

**Параметры:**
- `pivot_period`: Период для пивотных точек (по умолчанию: 5)
- `min_pivot_strength`: Минимальная сила точки (по умолчанию: 0.5)

### 2. OTT Strategy (Optimized Trend Tracker)
**Принцип работы:**
1. **Адаптивные скользящие средние**: VAR, EMA, SMA, WMA, TMA, WWMA, ZLEMA, TSF
2. **Определение трендов**: Анализ направления движения цены
3. **Сигналы разворота**: Пересечения OTT[2] и OTT[3]

**Параметры:**
- `length`: Период OTT (по умолчанию: 2)
- `percent`: Процент отклонения (по умолчанию: 1.4)
- `ma_type`: Тип скользящей средней (по умолчанию: "VAR")

### 3. Комбинированная стратегия ⭐
**Принцип работы:**
1. **Объединение стратегий**: GhostTangent + OTT
2. **Фильтрация сигналов**: Сделки только при совпадении
3. **Расчет уверенности**: 0-100% на основе силы сигналов
4. **Снижение рисков**: 60-80% меньше ложных сигналов

## 🔧 Технические детали

### API Endpoints
- `GET /api/balance` - Баланс USDT
- `GET /api/balances` - Все балансы
- `GET /api/positions` - Открытые позиции
- `GET /api/klines/<symbol>` - Исторические данные
- `POST /api/backtest` - Запуск бэктеста
- `POST /api/trading/start` - Запуск торговли
- `POST /api/trading/stop` - Остановка торговли

### WebSocket Events
- `trade_executed` - Выполнение сделки
- `price_update` - Обновление цены
- `error` - Ошибки

### Зависимости
- **Flask**: Веб-фреймворк
- **Flask-SocketIO**: WebSocket поддержка
- **pybit**: Bybit API клиент
- **pandas**: Обработка данных
- **matplotlib**: Графики (для CLI)

## 🚀 Быстрый старт

1. **Установка**: `pip install -r requirements.txt`
2. **Настройка**: Отредактируйте `config.py`
3. **Запуск**: `python web_app.py`
4. **Открытие**: `http://127.0.0.1:5000`

## 📈 Возможности бэктестинга

### Параметры
- **Плечо**: 1x-100x
- **Стоп-лосс**: 0.1%-50%
- **Начальный баланс**: Любая сумма
- **Размер позиции**: 1%-100%

- Общее количество сделок
- Процент прибыльных сделок

- Максимальная прибыль/убыток
- Средняя продолжительность сделки
- Причины выхода из позиций
