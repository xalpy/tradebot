# 🚀 Руководство по автоматической торговле

## Обзор

Новый интерфейс автоматической торговли позволяет настраивать разные стратегии для разных торговых инструментов и управлять торговлей через удобный веб-интерфейс.

## 🎯 Основные возможности

### 1. Автоматическая торговля
- ✅ Запуск/остановка торговли одним кликом
- ✅ Настройка стратегий для каждого инструмента отдельно
- ✅ Мониторинг статуса в реальном времени
- ✅ Лог всех операций

### 2. Настройка стратегий по инструментам
- ✅ **Ghost Strategy** - агрессивная стратегия для волатильных активов
- ✅ **OTT Strategy** - консервативная стратегия для стабильных активов  
- ✅ **Combined Strategy** - комбинированный подход

### 3. Гибкие настройки
- ✅ Плечо для покупки и продажи
- ✅ Процент от баланса на сделку
- ✅ Стоп-лосс и тейк-профит
- ✅ Временной интервал анализа
- ✅ Режим торговли (тестовый/реальный)

## 📋 Пошаговая инструкция

### Шаг 1: Выбор торговых пар
1. Откройте вкладку **"Торговля"**
2. В разделе **"Выбор торговых пар"**:
   - Выберите популярные пары из списка
   - Или найдите нужные пары через поиск
   - Или выберите все пары кнопкой "Выбрать все"

### Шаг 2: Настройка общих параметров
В разделе **"Общие настройки"** укажите:
- **Плечо покупки/продажи** (по умолчанию 10x)
- **% от баланса на сделку** (по умолчанию 3%)
- **Стоп-лосс** (по умолчанию 20%)
- **Тейк-профит** (опционально)
- **Интервал проверки** (по умолчанию 60 сек)
- **Режим торговли** (тестовый/реальный)

### Шаг 3: Настройка стратегий по инструментам
В таблице **"Настройки стратегий по инструментам"**:

1. **Добавьте стратегии** для выбранных пар
2. **Выберите стратегию** для каждой пары:
   - `Ghost` - для BTC, ETH, SOL (волатильные)
   - `OTT` - для стабильных альткоинов
   - `Combined` - для мемкоинов и новых активов
3. **Настройте параметры** для каждой пары:
   - Интервал анализа
   - Плечо
   - Стоп-лосс
   - Тейк-профит
   - % от баланса

### Шаг 4: Сохранение и запуск
1. Нажмите **"Сохранить все"** для сохранения стратегий
2. Нажмите **"Запустить"** для начала торговли
3. Следите за логом торговли в реальном времени

## 🎛️ Управление торговлей

### Статус торговли
- **Остановлена** - торговля не активна
- **Активна** - торговля работает, сделки выполняются

### Мониторинг
- **Активные пары** - количество выбранных инструментов
- **Открытые позиции** - текущие позиции
- **Последняя сделка** - время последней операции
- **Общий PnL** - прибыль/убыток

### Лог торговли
- Все операции записываются в лог
- Можно очистить или экспортировать лог
- Цветовая индикация: зеленый (успех), красный (ошибка), желтый (предупреждение)

## 📊 Рекомендации по стратегиям

### По типам активов:

| Тип актива | Рекомендуемая стратегия | Причина |
|------------|------------------------|---------|
| **BTC, ETH** | OTT | Стабильные, предсказуемые движения |
| **SOL, AVAX, DOT** | Ghost | Высокая волатильность, быстрые движения |
| **DOGE, SHIB** | Combined | Мемкоины, непредсказуемое поведение |
| **ADA, XRP** | OTT | Средняя волатильность |
| **LINK, MATIC** | Ghost | Технические активы с трендами |

### По волатильности:

| Волатильность | Стратегия | Настройки |
|---------------|-----------|-----------|
| **Высокая** | Ghost | Стоп-лосс 15-25%, плечо 5-10x |
| **Средняя** | OTT | Стоп-лосс 20-30%, плечо 10-20x |
| **Низкая** | Combined | Стоп-лосс 25-40%, плечо 15-30x |

## ⚠️ Важные замечания

### Безопасность
- Всегда начинайте с **тестового режима**
- Используйте **небольшие суммы** для начала
- **Мониторьте** торговлю регулярно

### Настройки
- **Минимальная стоимость ордера** - 5 USDT
- **Максимальное плечо** - 100x
- **Интервал проверки** - от 10 до 3600 секунд

### Стратегии
- **Ghost** - более агрессивная, больше сделок
- **OTT** - более консервативная, меньше сделок
- **Combined** - баланс между агрессивностью и консервативностью

## 🔧 Устранение неполадок

### Ошибка "Order does not meet minimum order value"
- Увеличьте процент от баланса на сделку
- Или выберите более дорогие активы

### Ошибка "Missing some parameters"
- Проверьте настройки API в config.py
- Убедитесь, что все обязательные поля заполнены

### Торговля не запускается
- Проверьте подключение к интернету
- Убедитесь, что API ключи корректны
- Проверьте лог на наличие ошибок
