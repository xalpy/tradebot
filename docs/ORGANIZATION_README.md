# 🧹 Организация проекта TradeBot

Этот набор скриптов поможет организовать файлы проекта, распределить тесты по папкам и создать документацию.

## 📋 Доступные скрипты

### 🎯 `cleanup_project.py` - Главный скрипт
**Полная организация проекта одним запуском**

```bash
python cleanup_project.py
```

**Что делает:**
- ✅ Создает резервную копию
- ✅ Организует файлы по папкам
- ✅ Создает документацию
- ✅ Очищает временные файлы
- ✅ Генерирует отчет

### 📁 `organize_project.py` - Организация файлов
**Перемещает файлы по соответствующим папкам**

```bash
python organize_project.py
```

**Создает структуру:**
```
tests/
├── chart_tests/     # Тесты графиков
├── data_tests/      # Тесты данных
├── strategy_tests/  # Тесты стратегий
├── api_tests/       # Тесты API
└── ui_tests/        # Тесты интерфейса

debug/               # Отладочные файлы
temp/                # Временные файлы
logs/                # Логи
```

### 📝 `create_test_readmes.py` - Документация
**Создает README файлы для всех папок с тестами**

```bash
python create_test_readmes.py
```

**Создает:**
- README.md в каждой папке с тестами
- Основной README.md в папке tests/
- Описание каждого теста
- Инструкции по запуску

## 🗂️ Структура после организации

Тесты данных и их валидации
- `test_data_types.py` - Типы данных

- `test_real_data.py` - Реальные данные

### 📈 tests/strategy_tests/
Тесты торговых стратегий
- `test_combined_strategy.py` - Комбинированная стратегия
- `test_advanced_backtest.py` - Расширенный бэктест
- `test_new_backtest.py` - Новый бэктестер

### 🔌 tests/api_tests/
Тесты API Bybit
- `test_api.py` - Базовые тесты

### 🖥️ tests/ui_tests/
Тесты пользовательского интерфейса

Отладочные файлы

## 🔒 Безопасность

### Резервные копии
- Автоматически создается резервная копия в `backup/`
- Временная метка в названии папки
- Все файлы сохраняются перед перемещением

### Проверки
- Проверка существования файлов
- Проверка прав доступа
- Обработка ошибок

## ⚠️ Важные замечания

### Перед запуском
1. Убедитесь, что вы в корневой папке проекта
2. Проверьте, что все основные файлы на месте
3. Закройте все открытые файлы

### После организации
1. Проверьте, что все файлы перемещены корректно
2. Обновите импорты в тестах, если необходимо
3. Запустите тесты для проверки работоспособности

## 🛠️ Ручная организация

Если автоматические скрипты не подходят, можно организовать файлы вручную:

### Создание папок
```bash
mkdir -p tests/{chart_tests,data_tests,strategy_tests,api_tests,ui_tests}
mkdir -p debug temp logs
```

### Перемещение файлов
```bash
# Тесты графиков
mv test_chart*.html tests/chart_tests/
mv test_chart_data.py tests/chart_tests/

# Тесты данных
mv test_data*.py tests/data_tests/
mv compare_data.py tests/data_tests/

# И так далее...
```

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте логи в консоли
2. Убедитесь, что все файлы на месте
3. Проверьте права доступа к папкам
4. Восстановите из резервной копии при необходимости
