# Система сохранения стратегий торгового бота

## Обзор

Теперь торговый бот автоматически сохраняет все настроенные стратегии в JSON файл и восстанавливает их при перезагрузке страницы. Это решает проблему потери настроек после перезагрузки.

## Основные функции

### 🔄 Автоматическое сохранение
- Все изменения стратегий автоматически сохраняются в файл `symbol_strategies.json`
- Настройки торговли сохраняются в localStorage браузера
- При перезагрузке страницы все настройки восстанавливаются

### 📋 Управление стратегиями
- **Добавить стратегию**: Нажмите кнопку "Добавить стратегию" и введите торговую пару
- **Сохранить все**: Сохраняет все текущие стратегии в файл
- **Загрузить**: Загружает стратегии из файла
- **Экспорт**: Скачивает все стратегии в JSON файл
- **Импорт**: Загружает стратегии из JSON файла
- **Очистить**: Удаляет все стратегии

### ⚙️ Настройки стратегий
Для каждой торговой пары можно настроить:
- **Стратегия**: Ghost, OTT, Combined
- **Интервал**: 1m, 5m, 15m, 30m, 1h, 4h, 1D
- **Плечо**: 1x - 100x
- **Стоп-лосс**: % от цены входа
- **Тейк-профит**: % от цены входа (можно отключить)
- **% от баланса**: Размер позиции

## Файлы

### symbol_strategies.json
Основной файл с сохраненными стратегиями:
```json
{
  "BTCUSDT": {
    "type": "combined",
    "timeframe": "15",
    "leverage": 10,
    "stop_loss": 20,
    "take_profit": 50,
    "balance_pct": 3
  }
}
```

### example_strategies.json
Пример файла с демонстрационными стратегиями для импорта.

## Использование

### 1. Настройка стратегий
1. Перейдите на вкладку "Торговля"
2. Выберите торговые пары в разделах "Популярные пары" или "Все пары"
3. Настройте параметры стратегий в таблице
4. Все изменения автоматически сохраняются

### 2. Экспорт/Импорт
1. **Экспорт**: Нажмите кнопку "Экспорт" для скачивания файла с стратегиями
2. **Импорт**: Нажмите кнопку "Импорт" и выберите JSON файл со стратегиями

### 3. Восстановление после перезагрузки
При перезагрузке страницы:
- Автоматически загружаются сохраненные стратегии
- Восстанавливаются настройки торговли
- Восстанавливается статус торговли
- Отмечаются выбранные торговые пары

## Логирование

Все действия записываются в лог торговли:
- ✅ Сохранение стратегий
- 📋 Загрузка стратегий
- 📤 Экспорт стратегий
- 📥 Импорт стратегий
- 🗑️ Удаление стратегий
- ⚙️ Сохранение настроек

## Безопасность

- Все данные сохраняются локально
- API ключи не сохраняются в файлах стратегий
- Можно экспортировать настройки для резервного копирования

## Устранение неполадок

### Стратегии не загружаются
1. Проверьте, что файл `symbol_strategies.json` существует
2. Проверьте права доступа к файлу
3. Посмотрите логи в консоли браузера

### Ошибки сохранения
1. Проверьте права записи в папку проекта
2. Убедитесь, что файл не заблокирован другим процессом
3. Проверьте свободное место на диске

### Проблемы с импортом
1. Убедитесь, что файл имеет правильный JSON формат
2. Проверьте структуру данных в файле
3. Используйте `example_strategies.json` как шаблон
