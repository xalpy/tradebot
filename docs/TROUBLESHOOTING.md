# Устранение проблем с сохранением стратегий

## Проблема: Стратегии не сохраняются в файл

### Диагностика

1. **Проверьте консоль браузера** (F12 → Console):
   - Ищите ошибки с префиксом ❌
   - Проверьте логи с префиксом 🔄 (загрузка) и 📡 (ответ сервера)

2. **Проверьте логи сервера**:
   - Запустите `web_app.py` и смотрите вывод в терминале
   - Ищите сообщения о сохранении стратегий

3. **Проверьте файл стратегий**:
   ```bash
   cat symbol_strategies.json
   ```

### Решения

#### 1. Проблема с правами доступа
```bash
# Проверьте права на папку
ls -la symbol_strategies.json

# Если нужно, измените права
chmod 666 symbol_strategies.json
```

#### 2. Проблема с форматом данных
- Убедитесь, что стратегии отправляются в правильном формате
- Проверьте консоль браузера на ошибки валидации

#### 3. Проблема с API
- Запустите тестовый скрипт: `python test_api.py`
- Убедитесь, что сервер отвечает на запросы

### Тестирование

1. **Ручное тестирование**:
   ```bash
   python test_strategies.py
   ```

2. **API тестирование**:
   ```bash
   python test_api.py
   ```

3. **Браузерное тестирование**:
   - Откройте DevTools (F12)
   - Перейдите на вкладку "Торговля"
   - Настройте стратегию и проверьте логи

### Логи для отладки

#### В браузере (Console):
```
🔄 Сохраняем стратегии: {BTCUSDT: {...}}
📡 Ответ сервера: 200 OK
✅ Результат сохранения: {status: "ok", strategies: {...}}
```

#### На сервере:
```
Сохраняем стратегии в файл: {'BTCUSDT': {...}}
✅ Стратегии успешно сохранены в symbol_strategies.json
```

### Частые ошибки

1. **"Ошибка сохранения: 500 Internal Server Error"**
   - Проверьте права доступа к файлу
   - Проверьте свободное место на диске

2. **"Ошибка сохранения: 400 Bad Request"**
   - Проверьте формат данных стратегий
   - Убедитесь, что все поля имеют правильные типы

3. **"Файл не найден"**
   - Убедитесь, что `symbol_strategies.json` существует
   - Проверьте путь к файлу

### Восстановление

Если файл стратегий поврежден:
```bash
# Создайте резервную копию
cp symbol_strategies.json symbol_strategies.json.backup

# Создайте новый файл
echo '{}' > symbol_strategies.json
```

### Контакты

Если проблема не решается:
1. Проверьте логи сервера и браузера
2. Запустите тестовые скрипты
3. Создайте issue с описанием проблемы и логами
