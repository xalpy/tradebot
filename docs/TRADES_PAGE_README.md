# Страница истории сделок (/trades)

## Описание

Новая страница `/trades` предоставляет детальный анализ истории сделок с автоматическим расчетом прибылей и убытков по всем торговым парам.

## Функциональность

### 📊 Основные возможности

1. **Получение данных из Bybit API** - автоматическое получение истории исполненных сделок
2. **Группировка по символам** - объединение сделок по торговым парам
3. **Расчет PnL** - автоматический подсчет прибыли/убытка для каждой пары
4. **Статистика** - общая статистика по всем сделкам
5. **Детальный просмотр** - возможность посмотреть все сделки по конкретной паре

### 🧮 Алгоритм расчета PnL

```python
# Для каждой торговой пары:
avg_buy_price = total_buy_value / total_buy_qty
avg_sell_price = total_sell_value / total_sell_qty

# PnL = (средняя цена продажи - средняя цена покупки) * количество - комиссии
min_qty = min(total_buy_qty, total_sell_qty)
pnl = (avg_sell_price - avg_buy_price) * min_qty - total_fees
```

### 📈 Отображаемая информация

**Общая статистика:**
- Количество торговых пар
- Общая прибыль/убыток
- Общее количество сделок
- Общие комиссии

**По каждой торговой паре:**
- Символ (например, BTCUSDT)
- Объем покупок (количество + стоимость)
- Объем продаж (количество + стоимость)
- PnL в USDT и процентах
- Общие комиссии
- Количество сделок

**Детали сделок:**
- Время исполнения
- Тип сделки (Buy/Sell)
- Количество
- Цена исполнения
- Сумма сделки
- Комиссия

### GET /trades
Отображает HTML страницу с историей сделок.

## Использование

1. **Запустите веб-приложение:**
   ```bash
   python web_app.py
   ```

2. **Откройте страницу:**
   ```
   http://localhost:5000/trades
   ```

3. **Навигация:**
   - Используйте кнопку "Обновить" для получения актуальных данных
   - Нажмите на количество сделок для просмотра деталей
   - Переключайтесь между страницами через навигационное меню

## Стилизация

- **Адаптивный дизайн** - работает на всех устройствах
- **Цветовая индикация** - зеленый для прибыли, красный для убытков
- **Bootstrap 5** - современный и красивый интерфейс
- **Font Awesome** - иконки для лучшего UX

## Ограничения

- Максимум 50 сделок за запрос (ограничение Bybit API)
- Расчет PnL упрощенный (средние цены покупки/продажи)
- Не учитывает частичные закрытия позиций
- Данные обновляются только при ручном обновлении
