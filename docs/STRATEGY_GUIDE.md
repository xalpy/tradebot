# GhostTangent Strategy Guide

## Обзор стратегии

GhostTangent Strategy - это торговая стратегия, основанная на определении пивотных точек (pivot points) и их использовании для генерации сигналов входа и выхода из позиций.

## Принцип работы

### 1. Определение пивотных точек

Стратегия ищет локальные максимумы и минимумы в ценовых данных:

- **Pivot High**: Локальный максимум, где цена выше соседних баров
- **Pivot Low**: Локальный минимум, где цена ниже соседних баров

### 2. Генерация сигналов

- **Buy Signal**: Генерируется при обнаружении нового Pivot Low
- **Sell Signal**: Генерируется при обнаружении нового Pivot High

### 3. Логика "двойных сигналов"

Стратегия использует продвинутую логику управления позициями:

1. **Открытие позиции**: При получении сигнала открывается позиция в соответствующем направлении
2. **Разворот позиции**: При получении противоположного сигнала текущая позиция закрывается и открывается новая
3. **Стоп-лосс**: Позиция автоматически закрывается при достижении заданного уровня убытка

## Параметры стратегии

### Основные параметры

- `pivot_period`: Период для определения пивотных точек (по умолчанию: 5)
- `min_pivot_strength`: Минимальная сила пивотной точки (по умолчанию: 0.5)

### Параметры торговли

- `leverage`: Плечо для торговли (1x-100x)
- `stop_loss_pct`: Процент стоп-лосса (0.1%-50%)
- `take_profit_pct`: Процент тейк-профита (0.1%-100%, опционально)
- `trade_size_pct`: Размер позиции в процентах от баланса (1%-100%)

## Примеры использования

### Базовый бэктест

```python
from strategy import GhostTangentStrategy
from backtester import Backtester

strategy = GhostTangentStrategy()
backtester = Backtester(strategy)
trades = backtester.run(df)
```

### Продвинутый бэктест с параметрами

```python
trades = backtester.run_with_params(
    df, 
    leverage=10,           # 10x плечо
    stop_loss_pct=2.0,     # 2% стоп-лосс
    take_profit_pct=3.0,   # 3% тейк-профит
    initial_balance=1000,  # $1000 начальный баланс
    trade_size_pct=3.0     # 3% от баланса на сделку
)
```

## Анализ результатов

### Метрики производительности

- **Total Trades**: Общее количество сделок
- **Win Rate**: Процент прибыльных сделок
- **Total Profit**: Общая прибыль в процентах и долларах
- **Max Profit/Loss**: Максимальная прибыль и убыток
- **Average Duration**: Средняя продолжительность сделки

### Причины выхода из позиций

- **Signal**: Выход по противоположному сигналу
- **Stop Loss**: Выход по стоп-лоссу
- **Take Profit**: Выход по тейк-профиту
- **Period End**: Закрытие в конце тестового периода

## Оптимизация стратегии

### Настройка параметров

1. **Период пивотных точек**: Увеличьте для более стабильных сигналов
2. **Плечо**: Выше плечо = больше риск/прибыль
3. **Стоп-лосс**: Меньший стоп-лосс = больше сделок, но меньше убытков
4. **Размер позиции**: Меньший размер = меньше риск

### Рекомендации

- Тестируйте на разных временных интервалах
- Используйте разные периоды для разных рынков
- Начинайте с низкого плеча (1x-5x)
- Устанавливайте стоп-лосс не более 2-3%

## Риски и ограничения

### Основные риски

- **Рыночные риски**: Стратегия может не работать в боковых рынках
- **Проскальзывание**: Реальные цены могут отличаться от исторических
- **Комиссии**: Не учитываются в бэктесте
- **Ликвидность**: Может быть недостаточно ликвидности для крупных позиций

### Ограничения

- Стратегия работает лучше на трендовых рынках
- Требует достаточной волатильности
- Может генерировать много ложных сигналов в боковике

## Мониторинг и управление

### Ключевые индикаторы

- **Drawdown**: Максимальная просадка
- **Sharpe Ratio**: Соотношение риск/доходность
- **Profit Factor**: Соотношение прибыли к убыткам

### Управление рисками

- Диверсификация по нескольким активам
- Ограничение размера позиции
- Использование стоп-лоссов
- Регулярный мониторинг производительности
