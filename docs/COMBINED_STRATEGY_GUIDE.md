# Комбинированная стратегия (GhostTangent + OTT)

## Обзор

Комбинированная стратегия объединяет две мощные торговые стратегии:
- **GhostTangent Strategy**: Основана на определении пивотных точек
- **OTT Strategy**: Optimized Trend Tracker, основан на адаптивных скользящих средних

Сделки совершаются только при совпадении сигналов обоих индикаторов, что значительно снижает количество ложных сигналов.

## Принцип работы

### 1. Генерация сигналов

Каждая стратегия генерирует свои сигналы независимо:

**GhostTangent:**
- Buy сигнал при обнаружении нового Pivot Low
- Sell сигнал при обнаружении нового Pivot High

**OTT:**
- Buy сигнал при пересечении OTT[2] выше OTT[3]
- Sell сигнал при пересечении OTT[2] ниже OTT[3]

### 2. Фильтрация сигналов

Система анализирует все сигналы и находит совпадения:
- ✅ **Совпадающие сигналы**: Обе стратегии дают сигнал в одном направлении
- ❌ **Противоречивые сигналы**: Стратегии дают противоположные сигналы
- ⚠️ **Одиночные сигналы**: Сигнал только от одной стратегии

### 3. Расчет уверенности

Для каждого совпадающего сигнала рассчитывается уровень уверенности:

```
Уверенность = (GhostStrength * 0.6 + OTTStrength * 0.4) * 100%
```

Где:
- **GhostStrength**: Нормализованная сила пивотной точки (0-1)
- **OTTStrength**: Нормализованная сила сигнала OTT (0-1)

## Параметры стратегий

### GhostTangent параметры
- `pivot_period`: Период для определения пивотных точек (по умолчанию: 5)
- `min_pivot_strength`: Минимальная сила пивотной точки (по умолчанию: 0.5)

### OTT параметры
- `length`: Период OTT (по умолчанию: 2)
- `percent`: Процент отклонения (по умолчанию: 1.4)
- `ma_type`: Тип скользящей средней ("VAR", "EMA", "SMA", "WMA", "TMA", "WWMA", "ZLEMA", "TSF")

## Преимущества комбинированной стратегии

### 1. Снижение ложных сигналов
- Фильтрация через два независимых индикатора
- Сделки только при подтверждении обеими стратегиями

### 2. Повышение точности
- GhostTangent лучше работает на волатильных рынках
- OTT лучше определяет тренды

### 3. Адаптивность
- Автоматическая настройка под рыночные условия
- Динамический расчет уверенности

### 4. Анализ рыночных условий
- Определение тренда (bullish/bearish)
- Оценка волатильности (low/medium/high)
- Рекомендации по торговле

## Статистика стратегий

Система отслеживает следующие метрики:

- **Total Signals**: Общее количество сигналов от обеих стратегий
- **Combined Signals**: Количество совпадающих сигналов
- **Ghost Only**: Сигналы только от GhostTangent
- **OTT Only**: Сигналы только от OTT
- **Conflicting**: Противоречивые сигналы
- **Average Confidence**: Средняя уверенность в совпадающих сигналах

## Примеры использования

### Базовый бэктест
```python
from combined_strategy import CombinedStrategy
from backtester import Backtester

strategy = CombinedStrategy()
backtester = Backtester(strategy)
trades = backtester.run_combined_strategy(df, leverage=10, stop_loss_pct=2.0)
```

### Настройка параметров
```python
strategy = CombinedStrategy(
    ghost_pivot_period=7,      # Более консервативный GhostTangent
    ghost_min_strength=0.7,    # Более сильные пивотные точки
    ott_length=3,              # Более медленный OTT
    ott_percent=2.0,           # Больше отклонение
    ott_ma_type="EMA"          # Экспоненциальная средняя
)
```

### Анализ статистики
```python
stats = strategy.get_strategy_stats()
print(f"Совпадающих сигналов: {stats['combined_percentage']}%")
print(f"Средняя уверенность: {stats['avg_confidence']}%")
```

## Интерпретация результатов

### Уровни уверенности
- **80-100%**: Очень высокая уверенность, сильные сигналы
- **60-79%**: Высокая уверенность, хорошие сигналы
- **40-59%**: Средняя уверенность, умеренные сигналы
- **0-39%**: Низкая уверенность, слабые сигналы

### Рыночные условия
- **favorable_for_buy**: Благоприятные условия для покупки
- **favorable_for_sell**: Благоприятные условия для продажи
- **high_risk**: Высокий риск, осторожность
- **low_opportunity**: Низкие возможности для торговли
- **neutral**: Нейтральные условия

## Оптимизация

### Настройка для разных рынков

**Волатильные рынки:**
- Увеличьте `ghost_min_strength` до 0.8-1.0
- Уменьшите `ott_percent` до 1.0-1.2

**Трендовые рынки:**
- Уменьшите `ghost_pivot_period` до 3-4
- Увеличьте `ott_length` до 3-4

**Боковые рынки:**
- Увеличьте `ghost_pivot_period` до 7-10
- Используйте `ott_ma_type="SMA"`

### Рекомендации по плечу
- **Высокая уверенность (80%+)**: 10x-20x плечо
- **Средняя уверенность (60-79%)**: 5x-10x плечо
- **Низкая уверенность (40-59%)**: 2x-5x плечо
- **Очень низкая уверенность (<40%)**: 1x плечо или пропуск

## Риски и ограничения

### Основные риски
- **Меньше сигналов**: Фильтрация может пропустить хорошие возможности
- **Задержка входа**: Ожидание подтверждения от обеих стратегий
- **Сложность настройки**: Больше параметров для оптимизации

### Ограничения
- Требует достаточного количества данных для работы
- Может не работать в очень спокойных рынках
- Нужна тщательная настройка параметров

## Мониторинг и управление

### Ключевые индикаторы
- Процент совпадающих сигналов (цель: >30%)
- Средняя уверенность (цель: >60%)
- Соотношение прибыльных сделок
- Максимальная просадка

### Управление рисками
- Динамическое изменение размера позиции на основе уверенности
- Использование стоп-лоссов
- Диверсификация по нескольким активам
- Регулярный анализ производительности
