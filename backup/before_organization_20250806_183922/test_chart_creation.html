Тест создания графика

📋 Инструкции:

  1. Запустите сервер: python web_app.py
  2. Откройте этот файл в браузере
  3. Нажмите "Проверить сервер" для проверки подключения
  4. Нажмите "Создать график" для тестирования
  5. Нажмите "Тест реальных данных" для анализа API

💡 Если сервер не доступен: Убедитесь, что Flask приложение запущено на порту 5000
