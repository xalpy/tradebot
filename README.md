# 🚀 Trading Bot Dashboard

Современный веб-интерфейс для торгового бота с поддержкой Bybit API и продвинутыми торговыми стратегиями.

## ✨ Ключевые возможности

### 🔄 Реальное время
- WebSocket соединение для обновления цен
- Уведомления о сделках в реальном времени
- Мониторинг позиций и балансов

### 📈 Продвинутый бэктестинг
- **3 торговые стратегии**: GhostTangent, OTT, Комбинированная
- Настройка плеча (1x-100x)
- Стоп-лосс (0.1%-50%)
- Размер позиции (1%-100%)
- Анализ причин выхода из позиций
- Уровень уверенности в сигналах

### 🎨 Современный интерфейс
- Темный градиентный дизайн
- Анимации и эффекты
- Адаптивная верстка
- Интерактивные графики LightweightCharts

### 🤖 Автоматическая торговля
- Логика "двойных сигналов"
- Автоматическое управление позициями
- Настройка параметров риска
- Мониторинг производительности

## 🛠 Быстрая установка

1. **Установка зависимостей:**
```bash
pip install -r requirements.txt
```

2. **Настройка API ключей в `config.py`**

3. **Запуск веб-приложения:**
```bash
python web_app.py
```

4. **Открытие в браузере:** `http://127.0.0.1:5000`

## 📊 Торговые стратегии

### 1. GhostTangent Strategy
- Основана на определении пивотных точек (pivot high/low)
- Сигналы входа и выхода
- Логика "двойных сигналов" для разворота позиций

### 2. OTT Strategy (Optimized Trend Tracker)
- Адаптивные скользящие средние
- Определение трендов и разворотов
- Множество типов MA (VAR, EMA, SMA, WMA, TMA, WWMA, ZLEMA, TSF)

### 3. Комбинированная стратегия ⭐
- Объединение GhostTangent и OTT
- Сделки только при совпадении сигналов
- Расчет уровня уверенности (0-100%)
- Снижение ложных сигналов на 60-80%

## 📈 Возможности бэктестинга

### Параметры
- **Плечо**: 1x-100x
- **Стоп-лосс**: 0.1%-50%
- **Начальный баланс**: Любая сумма
- **Размер позиции**: 1%-100%

### Метрики
- Общее количество сделок
- Процент прибыльных сделок
- Общая прибыль (% и $)
- Максимальная прибыль/убыток
- Средняя продолжительность сделки
- Причины выхода из позиций
- Уровень уверенности в сигналах

## 🔧 Конфигурация

### API ключи (`config.py`)
- `REAL_API_KEY` / `REAL_API_SECRET` - Реальная торговля
- `TEST_API_KEY` / `TEST_API_SECRET` - Тестовая торговля

### Параметры стратегий
- **GhostTangent**: `pivot_period`, `min_pivot_strength`
- **OTT**: `length`, `percent`, `ma_type`
- **Комбинированная**: Все параметры обеих стратегий

## 🚨 Риски и безопасность

### Основные риски
- Торговля криптовалютами связана с высокими рисками
- Используйте только те средства, которые можете позволить себе потерять
- Тестируйте стратегии на демо-счетах перед реальной торговлей

### Безопасность
- API ключи хранятся в отдельном файле
- Поддержка тестовых и реальных ключей
- Автоматическое переключение режимов
